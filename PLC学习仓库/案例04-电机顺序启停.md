# 案例04 电机顺序启停控制

## 📖 学习目标

1. 理解工业流水线中多台设备"顺序启动、逆序停止"的工程意义。
2. 掌握用 TON 定时器链实现多段延时的编程方法。
3. 学会用置位/复位标志 + 自锁触点处理"启动链"和"停止链"交织的控制逻辑。
4. 能独立编写三台电机顺序启停程序，并在 PLCSIM 中完成完整流程验证。

---

## 一、案例背景：流水线为什么要"排队"开机

设想一条面粉加工流水线，由三台设备组成：

1. **电机1——原料输送机**：把小麦送进车间；
2. **电机2——清理筛选机**：把输送来的原料除杂、筛选；
3. **电机3——研磨机**：把清理后的原料磨成面粉。

如果按下启动按钮让三台电机"轰"地一声同时启动，会发生什么？研磨机里空转还好说，但一旦物料堆积、下游设备没就绪，就会**堵料、过载、甚至损坏设备**。所以工程师们约定：**按物流方向依次启动**——先开输送机，等它转稳了 3 秒，再开筛选机；再等 3 秒，最后开研磨机，让物料像接力赛一样一棒一棒传下去。

停机时顺序要**反过来**：先停研磨机（不再进新料），3 秒后停筛选机（把里面的料处理完），再 3 秒后停输送机（把管道里的料送干净）。这就是工业控制中非常经典的**"顺序启动、逆序停止"**，也叫"先启先停链"或"序控启停"。它广泛应用于皮带输送线、灌装线、中央空调机组、矿山选矿流水线等场合。

**不这样做会怎样？** 如果停机时先停上游，下游空转会浪费电；如果下游停了上游还在送料，物料会堆成小山。所以"谁先谁后"不是拍脑袋定的，而是由**工艺**决定的，PLC 程序只是把工艺要求翻译成逻辑。

---

## 二、控制要求

1. **启动**：按下启动按钮（点动）——
   - 电机1 **立即启动**；
   - 延时 **3 秒**后电机2 自动启动；
   - 再延时 **3 秒**后电机3 自动启动。
2. **停止**：按下停止按钮（点动）——
   - 电机3 **立即停止**；
   - 延时 **3 秒**后电机2 自动停止；
   - 再延时 **3 秒**后电机1 自动停止，整个系统回到待机状态。
3. **保护**：热继电器过载动作时，三台电机立即全部停止。
4. **附加**：系统运行期间，运行指示灯常亮。
5. 停止过程中如果又按启动按钮，系统不理会，必须等停止流程走完再重新启动（避免设备状态混乱）。

## 四、实现思路：定时器链式控制

### 4.1 核心思想

把整个流程拆成**两条链**：

- **启动链**：由"系统运行标志 M0.0"牵头，两个 TON 像**接力赛**一样首尾相连——第一个 TON 计满 3s 后，它的 Q 去启动第二个 TON，第二个 TON 再计 3s。每接力一次，就多开一台电机。
- **停止链**：由"停止进行中 M0.1"牵头，同样用两个 TON 接力，每接力一次，就多停一台电机。

**要点**：启动与停止不能"打架"。所以让启动链的源头（TON_启动延时1 的 IN）带上 `NOT M0.1`——一旦停止命令下达，启动链立刻"熄火"，不再开新电机；已经开着的电机则交给停止链按节奏逐台关闭。

### 4.2 控制流程示意

```
【启动流程】
按下启动按钮
   ↓（S 置位）
系统运行标志 M0.0 = 1
   ↓ 立即
电机1 Q0.0 运行 ──── 3s（TON_启动延时1）────→ 电机2 Q0.1 运行
                                                    ↓
                          电机3 Q0.2 运行 ←── 3s（TON_启动延时2）

【停止流程】
按下停止按钮
   ↓（S 置位，同时电机3 立即停止）
停止进行中 M0.1 = 1
   ↓ 启动 TON_停止延时1
3s 后：电机2 Q0.1 停止
   ↓ 启动 TON_停止延时2
3s 后：电机1 Q0.0 停止，复位 M0.0 / M0.1，系统回到待机
```

### 4.3 完整时序图

假设 t=0 秒按下启动，t=20 秒按下停止（每个字符代表 1 秒，# = 运行，. = 停止）：

```
时间(s)     0    3    6                 20   23   26
            |    |    |                 |    |    |
启动按钮     ^                                        (t=0 按下)
停止按钮                                    ^         (t=20 按下)
电机1 Q0.0  ##########################....
电机2 Q0.1  ...####################.......
电机3 Q0.2  ......##############..........
停止进行中  ....................######....
指示灯 Q0.4  ##########################....

解读：
  t=0   ：电机1 立即启动，指示灯亮
  t=3   ：TON_启动延时1 计时到，电机2 启动
  t=6   ：TON_启动延时2 计时到，电机3 启动，启动链走完
  t=20  ：按下停止，M0.1 置位 → 电机3 立即停止，TON_停止延时1 开始计时
  t=23  ：TON_停止延时1 计时到 → 电机2 停止，TON_停止延时2 开始计时
  t=26  ：TON_停止延时2 计时到 → 电机1 停止，M0.0/M0.1 复位，指示灯灭
```

### 4.4 定时器链的"接力"关系一览

| 定时器 | IN 端接什么 | PT | Q 端去干什么 |
|--------|------------|-----|-------------|
| TON_启动延时1 | M0.0 且非 M0.1 | T#3s | 启动 TON_启动延时2；驱动电机2 |
| TON_启动延时2 | TON_启动延时1.Q | T#3s | 驱动电机3 |
| TON_停止延时1 | M0.1 | T#3s | 停电机2；启动 TON_停止延时2 |
| TON_停止延时2 | TON_停止延时1.Q | T#3s | 停电机1；复位 M0.0 和 M0.1 |

## 五、梯形图程序与逐网络分析

### Network 1：启动命令——置位系统运行标志

```
     启动按钮 (I0.0)       系统运行标志 (M0.0)
    -------| |-------------------(S)---
```

**分析**：点动按下启动按钮，M0.0 置位并保持。M0.0 是整个启动链的"总开关"：它让电机1 立即转起来（Network 8），并接通启动链的第一个定时器（Network 3）。

### Network 2：停止命令——置位"停止进行中"

```
     停止按钮 (I0.1)  系统运行标志 (M0.0)  停止进行中 (M0.1)
    -------| |---------------| |-----------------(S)---
```

**分析**：只有在系统正在运行（M0.0=1）时按停止按钮，M0.1 才被置位——空载待机时误按停止没有任何效果。M0.1 置位后做三件事：立即掐断电机3（Network 10 的 --|/|--）；启动停止链第一个定时器（Network 5）；掐断启动链（Network 3 的 --|/|--）。

### Network 3：启动链第一棒——延时 3 秒

```
    系统运行标志    停止进行中           TON_启动延时1
  --| |--+-----------|/|----------------+---------------+
   (M0.0)|           (M0.1)              | TON           |
         |                               | IEC_TIMER     |
         |                               +---------------+
         |                               | IN         Q  |----→ 驱动电机2、启动下一棒
         |                        T#3s --| PT         ET |
         |                               +---------------+
```

**分析**：系统运行且未在停止过程中时，计时 3 秒。IN 端串联 M0.1 的常闭触点是本程序的**关键安全设计**：如果在启动等待期间（比如电机1 刚转 1 秒）按了停止，M0.1=1 会立即切断计时，电机2、电机3 永远不会再启动，只剩停止链去关电机1。

### Network 4：启动链第二棒——再延时 3 秒

```
   TON_启动延时1.Q                       TON_启动延时2
  --| |--+-------------------------------+---------------+
         |                               | TON           |
         |                               | IEC_TIMER     |
         |                               +---------------+
         |                               | IN         Q  |----→ 驱动电机3
         |                        T#3s --| PT         ET |
         |                               +---------------+
```

**分析**：第一棒计时到（电机2 启动的时刻），第二棒开始计时；再过 3 秒 Q=1，电机3 启动。这就是"定时器链"——后一个定时器由前一个的 Q 拉动，形成接力。

### Network 5：停止链第一棒——3 秒后停电机2

```
    停止进行中                           TON_停止延时1
  --| |--+-------------------------------+---------------+
   (M0.1)|                               | TON           |
         |                               | IEC_TIMER     |
         |                               +---------------+
         |                               | IN         Q  |----→ 停电机2、启动下一棒
         |                        T#3s --| PT         ET |
         |                               +---------------+
```

**分析**：M0.1 置位的瞬间（电机3 已在 Network 10 被 --|/|-- 断开），本定时器开始 3 秒计时。计时到 → 通过 Network 9 的常闭触点关掉电机2，同时启动第二棒。

### Network 6：停止链第二棒——再 3 秒后停电机1

```
   TON_停止延时1.Q                       TON_停止延时2
  --| |--+-------------------------------+---------------+
         |                               | TON           |
         |                               | IEC_TIMER     |
         |                               +---------------+
         |                               | IN         Q  |----→ 停电机1、复位系统
         |                        T#3s --| PT         ET |
         |                               +---------------+
```

**分析**：第二棒计时到（距停止命令共 6 秒），Q=1，一方面切断电机1（Network 8），一方面触发 Network 7 的系统复位。

### Network 7：停止流程收尾——复位两个标志

```
   TON_停止延时2.Q
  -------| |-------+-------(R)---  系统运行标志 (M0.0)
   热继电器 (I0.2) |
  -------| |-------+-------(R)---  停止进行中 (M0.1)
```

**分析**：两条并联支路——停止流程走完（TON_停止延时2.Q=1）或热继电器过载，都把 M0.0、M0.1 一并复位。M0.1 复位后，TON_停止延时1 的 IN=0，两棒停止定时器依次自动清零，系统回到干净的待机状态，等待下一次启动。热继电器复用此网络，保证过载时系统状态也被彻底清理。

### Network 8：电机1 输出

```
   系统运行标志 (M0.0)  TON_停止延时2.Q    热继电器 (I0.2)     电机1接触器 (Q0.0)
  --------| |----------------|/|----------------|/|----------------( )---
```

**分析**：三个条件串联——系统在运行、停止链第二棒未到、没有过载。启动瞬间 M0.0=1、其他两个常闭都通，电机1 立即运行；停止后第 6 秒 TON_停止延时2.Q 变 1，常闭断开，电机1 停止。

### Network 9：电机2 输出（带自锁）

```
   TON_启动延时1.Q     TON_停止延时1.Q    热继电器 (I0.2)     电机2接触器 (Q0.1)
  -------| |-------+-------|/|----------------|/|----------------( )---
   电机2接触器     |
  -------| |-------+
     (Q0.1 自锁)
```

**分析**：这是本程序**最容易被忽略的细节**。电机2 靠 TON_启动延时1.Q 得电；可一旦按下停止，M0.1=1 会让 Network 3 的计时器立即复位、Q 变 0——如果没有别的条件"托底"，电机2 会在停止瞬间跟着断电，失去"再运行 3 秒"的能力。解决办法是给电机2 并联一个**自锁触点 Q0.1**：电机2 一旦运行，就靠自己的输出触点维持通电，直到 TON_停止延时1.Q（3 秒后）用常闭触点把它断开。热继电器常闭串在最终输出，过载时无论哪条支路都断开。

### Network 10：电机3 输出（带自锁）

```
   TON_启动延时2.Q     停止进行中 (M0.1)  热继电器 (I0.2)     电机3接触器 (Q0.2)
  -------| |-------+-------|/|----------------|/|----------------( )---
   电机3接触器     |
  -------| |-------+
     (Q0.2 自锁)
```

**分析**：与 Network 9 同理，自锁维持运行状态。停止时 M0.1 的常闭触点**立即**断开回路——这正是"电机3 第一个停"的实现方式。启动时则要等 TON_启动延时2.Q（第二次 3 秒延时）才接通。

### Network 11：运行指示灯

```
     系统运行标志 (M0.0)    运行指示灯 (Q0.4)
    -------| |-------------------( )---
```

**分析**：M0.0 从启动保持到停止流程结束，指示灯全程常亮，向操作工提示"系统处于运行管理中（包括正在停机的过程）"。

### 关键设计点回顾

1. **电机3 为什么立即停？** 它的输出回路串了 M0.1 的常闭触点，停止命令一下达立即断开。
2. **电机2 为什么能撑 3 秒？** 靠 Q0.1 自锁触点托底，由 TON_停止延时1.Q 负责在 3 秒后断开。
3. **电机1 为什么能撑 6 秒？** 它由 M0.0 托底，而 M0.0 要等 TON_停止延时2.Q（6 秒）才被复位。
4. **停止过程中按启动为什么无效？** 启动链源头的 TON_启动延时1 的 IN 串着 M0.1 常闭，M0.1 复位前启动链被彻底封死。

### ② 启动仿真并下载程序

1. 菜单"编辑 → 全部编译"，确认无错误。
2. 选中 PLC_1，点击工具栏"开始仿真"，在 PLCSIM 中创建与组态一致的 CPU 站。
3. 回到 TIA Portal 点击"下载到设备"，按向导完成装载。
4. 将 PLCSIM 中的 CPU 切到 **RUN**。

### ③ 用监控表模拟输入信号

1. 添加监控表，录入上表变量，点击"监控"（眼镜）图标。
2. 启动：在 I0.0 修改值输入 1 → 回车 → 再输入 0 回车（模拟点动）；或直接点击 PLCSIM 精简视图中 I0.0 的小开关再点灭。
3. 停止：对 I0.1 做同样的"置 1 → 置 0"操作。
4. 过载：把 I0.2 置 1（保持），测完记得恢复为 0。

### ④ 预期结果

1. 初始：三个 Q 均为 0，四个定时器 ET 均为 T#0ms。
2. t=0 点动 I0.0：M0.0=1、Q0.0 立即=1、Q0.4=1；TON_启动延时1 的 ET 开始从 0 上涨。
3. **3 秒**：TON_启动延时1.Q=1 → Q0.1=1（电机2 启动），同时 TON_启动延时2 开始计时。
4. **再过 3 秒（t=6s）**：TON_启动延时2.Q=1 → Q0.2=1（电机3 启动），三台电机全部运行。
5. t=20s 点动 I0.1：M0.1=1，**Q0.2 立即=0**（电机3 第一个停）；TON_停止延时1 的 ET 开始计时。
6. **3 秒后（t=23s）**：Q0.1=0（电机2 停）；TON_停止延时2 开始计时。
7. **再过 3 秒（t=26s）**：Q0.0=0（电机1 停），同时 M0.0、M0.1 复位，Q0.4 灭，四个定时器 ET 全部归零。
8. 运行中把 I0.2 置 1：三台电机与指示灯立即全灭，M0.0/M0.1 复位。

## 📌 本章小结

1. "顺序启动、逆序停止"由工艺决定：启动按物流方向接力开机，停止按反方向接力关机，目的是防止堵料和设备损坏。
2. 实现套路 = **标志位 + 定时器链**：启动链由 M0.0 牵头，停止链由 M0.1 牵头，两个 TON 首尾接力各延时 3 秒。
3. 停止瞬间"该停的立即停"靠常闭触点（--|/|--）切断；"该多转 3 秒的"靠输出自锁触点托底，再由停止定时器到点断开。
4. 启动链的 IN 串入"停止进行中"常闭触点，实现"停止期间不接受启动"的互锁，这是工程思维的体现。
5. 热继电器在收尾网络中复位系统标志，同时每个电机输出回路都串有 --|/|-- 保护触点，双保险。

## ⚠️ 常见错误与注意事项

1. **停止按钮/热继电器触点类型搞反**：程序里写成常开触点 --| |--，结果一上电 M 区状态不对导致电机乱转或永远启动不了。教学接法牢记：停止与过载都用 --|/|-- 串联；实际工程硬件接常闭时程序改用常开，两者逻辑相反。
2. **停止时直接复位 M0.0**：按下停止就 (R) M0.0，三台电机瞬间全停，逆序停止变成"齐停"。复位必须放在 TON_停止延时2.Q 之后。
3. **漏掉电机2/3 的自锁触点**：停止时启动链定时器被 M0.1 切断，没有自锁的输出跟着掉电，逆序停止失效。凡是"靠定时器 Q 得电、停止后还要继续运行"的输出都必须自锁。
4. **启动链没有避开停止标志**：TON_启动延时1 的 IN 只接 M0.0，停止过程中电机2、电机3 还会照常启动。IN 必须串 M0.1 的常闭触点。
5. **一个定时器实例多处调用**：四个 TON 各自要用独立的背景 DB（TON_启动延时1、2，TON_停止延时1、2），实例复用会导致计时互相干扰。
6. **输出双线圈**：同一输出在多个网络使用普通线圈，只有最后一个网络生效。多条件控制同一输出时，用并联触点汇到一个线圈，或用置位/复位。
7. **停止过程中按启动导致状态错乱**：若没有 M0.1 对启动链的封锁，半停状态再启动会出现"部分电机运行、部分在停机"的混乱局面。互锁触点不能省。
8. **PT 时间写错或单位漏写**：T#3s 写成 3s、T#3，程序无法编译。按 T#数值单位 的格式书写。
9. **验证时没等定时器走完就下结论**：仿真时 3 秒看起来很短，但一定要用监控表里的 ET 数值核对时间，而不是凭感觉。
10. **下载后未置 RUN 或未勾选监视**：现象"程序没反应"多半是 CPU 在 STOP 或监控表没开监视，先查这些基本项再怀疑程序。

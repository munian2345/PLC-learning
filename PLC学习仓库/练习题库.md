# 练习题库——西门子 S7-1500 TIA Portal 25 道分级练习

本套题库配合《西门子1500 PLC从入门到精通》课程使用，共 25 题：基础 10 道、中级 10 道、高级 5 道。所有题目都可以在 TIA Portal + PLCSIM 仿真环境（CPU 1511-1 PN）中完成，无需实物硬件。

**统一引脚约定（与课程笔记一致，做题前先在变量表中建好）**：启动按钮 I0.0、停止按钮 I0.1、电机 Q0.0、正转 Q0.0、反转 Q0.1、报警灯 Q0.2、蜂鸣器 Q0.3、运行指示灯 Q0.4；温度 MW20（Int）、计数值 MW30（Int）、工程量 MD40（Real）；位存储器从 M0.0 起用；定时器/计数器一律使用 IEC 指令 + 背景数据块（实例用中文名，如「TON_延时启动」）。

**建议做题流程**：读题圈出输入/输出 → 建变量表 → 写程序（带注释）→ 按【附录A-PLCSIM仿真教程】下载仿真验证 → 再对照参考答案找差距。卡住了先翻【附录B-调试与故障诊断】的排查思路，别急着看答案。

## 一、基础篇（题 01~10）

### 题01｜电机点动控制

- **难度**：基础
- **控制要求**：按下启动按钮（I0.0），电机（Q0.0）立即转动；松开按钮，电机立即停止。点动常用于设备调试时的"点一下动一下"。
- **提示**：只用两个元素——一个常开触点、一个输出线圈，不需要自锁。
- **参考答案**：

```
网络1：电机点动
      启动按钮I0.0                       电机Q0.0
  ----| |---------------------------------( )----
```

**答案解读**：触点闭合的期间线圈就得电，触点断开线圈即失电——程序行为与按钮"同起同坐"。对比题02体会"点动"与"连续"的区别。

---

### 题02｜电机启保停连续运行

- **难度**：基础
- **控制要求**：按下启动按钮（I0.0），电机（Q0.0）开始连续运行；按下停止按钮（I0.1），电机停止。这是工业控制里最重要的基础电路，没有之一。
- **提示**：启动、停止、自锁三要素。自锁 = 用输出自己的常开触点并联在启动按钮两端。
- **参考答案**：

```
网络1：电机启保停
      启动按钮I0.0        停止按钮I0.1        电机Q0.0
  ----| |----------+-------|/|-------------( )----
                   |
      电机Q0.0     |
  ----| |----------+
     (自锁触点)
```

**答案解读**：按下启动，电流经 I0.0 使 Q0.0 得电；Q0.0 的自锁触点随即闭合，松开按钮后由自锁触点继续维持导通。停止按钮用常闭触点 --|/|--，按下（=1）时断开电路。

---

### 题03｜启停控制+运行指示灯

- **难度**：基础
- **控制要求**：在题02基础上增加：电机运行时，运行指示灯（Q0.4）同步点亮；电机停止，指示灯熄灭。
- **提示**：指示灯和电机受同一信号控制，用一个新网络并联输出即可，不必复制整套启保停逻辑。
- **参考答案**：

```
网络1：电机启保停
      启动按钮I0.0        停止按钮I0.1        电机Q0.0
  ----| |----------+-------|/|-------------( )----
                   |
      电机Q0.0     |
  ----| |----------+

网络2：运行指示灯
      电机Q0.0                         运行指示灯Q0.4
  ----| |---------------------------------( )----
```

**答案解读**：网络2 直接用 Q0.0 的触点驱动 Q0.4——"电机转，灯就亮"由程序结构保证，永远不会出现灯和电机不一致。现场惯例：能用程序保证的状态一致性，就不靠两个独立电路各自去凑。

### 题04｜电机正反转互锁控制

- **难度**：基础
- **控制要求**：按下正转按钮（I0.0）电机正转（Q0.0），按下反转按钮（I1.0）电机反转（Q0.1），停止按钮（I0.1）停机。正转和反转绝不允许同时接通（否则主电路相间短路）。要求软件互锁，并理解为什么还需要硬件互锁。
- **提示**：两套启保停，各串入对方的常闭触点做互锁；每路再加自锁。
- **参考答案**：

```
网络1：正转
      正转按钮I0.0        停止I0.1      反转Q0.1      正转Q0.0
  ----| |----------+--------|/|----------|/|----------( )----
                   |
      正转Q0.0     |
  ----| |----------+

网络2：反转
      反转按钮I1.0        停止I0.1      正转Q0.0      反转Q0.1
  ----| |----------+--------|/|----------|/|----------( )----
                   |
      反转Q0.1     |
  ----| |----------+
```

**答案解读**：正转回路串入 Q0.1 的常闭触点、反转回路串入 Q0.0 的常闭触点，两者互相"卡住"，这就是软件互锁。想切换方向必须先按停止。补充：真实接触器还要求硬件互锁（常闭触点串入对方线圈回路），因为若 PLC 输出模块短路粘连，软件互锁就失效了——软件与硬件双保险是行业规范。

### 题05｜置位/复位控制

- **难度**：基础
- **控制要求**：按下启动按钮（I0.0）后电机（Q0.0）运行，即使松开按钮也保持；按下停止按钮（I0.1）后电机停止并保持。要求用置位 (S)、复位 (R) 线圈实现，并与启保停对比。
- **提示**：S/R 不需要自锁触点，置位后的状态由系统"记住"，直到复位出现。
- **参考答案**：

```
网络1：置位
      启动按钮I0.0        停止按钮I0.1        电机Q0.0
  ----| |----------+-------|/|-------------(S)----
                   |

网络2：复位
      停止按钮I0.1                        电机Q0.0
  ----| |---------------------------------(R)----
```

**答案解读**：网络1 按下启动把 Q0.0 置 1 并保持；网络2 按下停止把 Q0.0 清 0。注意两点：网络1 中串入停止常闭，是为了"停止优先"（两按钮同时按下时不会启动）；S/R 与启保停效果相同，但 S/R 更适合后续扩展成步进顺序控制（见题23）。

### 题06｜延时启动控制

- **难度**：基础
- **控制要求**：按下启动按钮（I0.0）后，电机（Q0.0）不马上转，延时 5 秒后自动启动运行；按停止按钮（I0.1）随时停止。警示场景：启动大型设备前先预警、人员撤离。
- **提示**：IEC 接通延时定时器 TON，背景 DB 实例名「TON_延时启动」，PT 用 T#5S；定时器 IN 条件 = 启动标志，Q 输出再去驱动电机。
- **参考答案**：

```
网络1：启动标志（自锁）
      启动按钮I0.0        停止按钮I0.1        启动标志M0.0
  ----| |----------+-------|/|-------------( )----
                   |
      启动标志M0.0 |
  ----| |----------+

网络2：延时5秒
      启动标志M0.0      TON_延时启动
  ----| |------------(TON)----------
                     PT := T#5S     Q──( ) 电机Q0.0
```

**答案解读**：TON 的行为是"IN 接通持续满 PT，Q 才输出 1"。按启动后 M0.0 自锁，TON_延时开始计时，5 秒计满 Q=1，电机运行。中途按停止，M0.0 断开 → IN=0 → 定时器立即复位（ET 清零），下次启动重新计 5 秒——这个"中途取消就作废"的特性正好符合安全需求。

### 题07｜延时停止控制

- **难度**：基础
- **控制要求**：按下启动按钮（I0.0）电机（Q0.0）立即运行；按下停止按钮（I0.1）后电机不立即停，继续运行 3 秒再停（例如让传送带上的物料走完）。
- **提示**：停止信号先置位一个"延时停止标志"，用 TON（背景 DB「TON_延时停止」，PT=T#3S）计时，计满后再复位运行标志；电机运行期间标志要一直保持。
- **参考答案**：

```
网络1：运行标志
      启动按钮I0.0      延时停止M0.1(常闭)   停止按钮I0.1     运行标志M0.0
  ----| |----------+-------|/|-------------|/|------------( )----
                   |
      运行标志M0.0 |
  ----| |----------+

网络2：停止信号置位延时标志
      停止按钮I0.1      运行标志M0.0        延时停止M0.1
  ----| |--------------| |------------------(S)----

网络3：延时3秒后真正停止
      延时停止M0.1      TON_延时停止
  ----| |------------(TON)----------
                     PT := T#3S     Q──┬─(R) 运行标志M0.0
                                        └─(R) 延时停止M0.1

网络4：输出
      运行标志M0.0                         电机Q0.0
  ----| |----------------------------------( )----
```

**答案解读**：按停止 → M0.1 置位，M0.0 尚未复位（网络1 中 M0.1 的常闭此刻还没生效？注意：置位后下一网络才用 TON，电机在本周期继续输出）→ TON 计时 3 秒 → 同时复位运行标志与延时标志，电机停止。思考题：若把网络2 里的"运行标志 M0.0"触点去掉会怎样？（答案：停机后误碰停止按钮也会启动 3 秒延时，虽无输出但逻辑不干净。）

### 题08｜件数计数报警

- **难度**：基础
- **控制要求**：传送带上的产品经过光电传感器（I0.3，每来一件接通一次），计数器加 1，当前件数存入 MW30；累计 10 件时报警灯（Q0.2）常亮提醒清线；按下清零按钮（I0.4）计数和报警一起清零。
- **提示**：IEC 加计数器 CTU，背景 DB「CTU_件数计数」，CU 接传感器，R 接清零，PV=10，CV 输出送到 MW30；报警条件用比较触点 MW30 >= 10。
- **参考答案**：

```
网络1：计数
      产品传感器I0.3      CTU_件数计数
  ----| |--------------(CTU)------
      清零按钮I0.4 ──R    PV := 10
                         CV ──( ) 送到MW30
                         Q  ──(未用)

网络2：满件报警
      计数值MW30                           报警灯Q0.2
  ----| |>=10|-----------------------------( )----
                          (比较触点:MW30>=10)
```

**答案解读**：CTU 每在 CU 端收到一次上升沿 CV 加 1；R=1 时 CV 立即清零。Q 输出在本例可以不用（用比较指令实现报警更直观），但要知道 CTU 的 Q = "CV 是否达到 PV"。用比较触点而不是 CTU 的 Q，好处是以后改成"超过 10 报警、超过 20 蜂鸣器"时只需加网络，计数器本身不用动。

### 题09｜边沿检测与脉冲输出

- **难度**：基础
- **控制要求**：每按下一次启动按钮（I0.0），报警灯（Q0.2）点亮 2 秒后自动熄灭（无论按钮是否还按着）；连续快速按多次，每次都能触发一次 2 秒点亮。
- **提示**：先用 P 边沿触点把"按住不放"变成"单次脉冲"，再用 TP（脉冲定时器，背景 DB「TP_报警脉冲」，PT=T#2S）产生固定时长输出。TP 的特点是运行中不重触发。
- **参考答案**：

```
网络1：边沿检测
      启动按钮I0.0                         边沿脉冲M0.0
  ----|P|----------------------------------( )----
    (边沿存储位: M1.0)

网络2：2秒脉冲输出
      边沿脉冲M0.0      TP_报警脉冲
  ----| |------------(TP)----------
                     PT := T#2S    Q──( ) 报警灯Q0.2
```

**答案解读**：P 触点在 I0.0 从 0 变 1 的那个扫描周期导通一次（边沿存储位 M1.0 专用于此检测点，不能与其他 P 触点共用），M0.0 得到一个单周期脉冲触发 TP；TP 从触发时刻起把 Q 保持 1 整整 2 秒，期间 IN 变 0 也不影响。若把 TP 换成 TON 会怎样？按下满 2 秒才亮且按住才亮——体会 TP 与 TON 的差别是本题核心。

### 题10｜温度比较报警

- **难度**：基础
- **控制要求**：温度值存于 MW20（Int，单位 °C）。温度 > 50 时报警灯（Q0.2）亮；温度 >= 80 时蜂鸣器（Q0.3）也响。仿真时直接在监控表改 MW20 测试。
- **提示**：比较触点可以直接比较 Int 变量与常数；两个独立网络，各自的条件互相独立。
- **参考答案**：

```
网络1：高温报警灯
      温度MW20                            报警灯Q0.2
  ----| |>50|-----------------------------( )----
        (比较触点: MW20>50)

网络2：超温蜂鸣器
      温度MW20                            蜂鸣器Q0.3
  ----| |>=80|----------------------------( )----
        (比较触点: MW20>=80)
```

**答案解读**：比较触点左端写变量、下拉选择比较符（>、>=、<、<=、==、<>），右端写常数或另一变量。PLCSIM 验证：MW20 依次写 49→51→79→81，观察 Q0.2、Q0.3 的变化；注意 50 是"不报警、51 才报"的边界——调试边界值要专测"刚好达标的前后两个数"。

## 二、中级篇（题 11~20）

### 题11｜单按钮启停控制

- **难度**：中级
- **控制要求**：只允许用**一个**按钮（I0.0）：第一次按下电机（Q0.0）启动并保持，第二次按下电机停止，第三次又启动……如此往复。面板上没有停止按钮时的常见方案。
- **提示**：思路一：I0.0 做 P 边沿 → CTU 计数（背景 DB「CTU_单按钮」），计数到 2 自动清零，用"计数值=1"驱动输出。思路二：边沿 + 置位复位标志。推荐思路一，指令都用过。
- **参考答案**：

```
网络1：边沿计数（数到2自动清零，实现0→1→0→1循环）
      启动按钮I0.0       CTU_单按钮
  ----|P|-------------(CTU)------
      MW30>=2 ──R       PV := 2
      (边沿存储位M1.0)   CV ──( ) 送到MW30

网络2：计数为1时电机运行
      计数值MW30                          电机Q0.0
  ----|==1|-------------------------------( )----
```

**答案解读**：每按一次 CV 加 1：CV=1 电机运行；再按 CV=2 → R 条件成立计数器清零 → MW30=0 电机停止；再按又从 1 开始。整个"启停开关"被压缩成一个按钮。要点：R 输入接的是比较触点（MW30>=2），清零动作发生在同一个扫描周期内，外部看不出 CV 曾经到过 2。

### 题12｜两台电机顺序启动

- **难度**：中级
- **控制要求**：按下启动按钮（I0.0）：1 号电机（Q0.0）立即启动，5 秒后 2 号电机（Q0.1）自动启动；按下停止按钮（I0.1），两台同时停止。模拟"先开油泵、后开主机"的工艺顺序。
- **提示**：1 号电机走启保停；TON（「TON_电机2延时」，T#5S）的 IN 接运行标志，Q 直接驱动 2 号电机。
- **参考答案**：

```
网络1：运行标志
      启动按钮I0.0        停止按钮I0.1        运行标志M0.0
  ----| |----------+-------|/|-------------( )----
                   |
      运行标志M0.0 |
  ----| |----------+

网络2：1号电机立即运行
      运行标志M0.0                         电机1Q0.0
  ----| |----------------------------------( )----

网络3：5秒后2号电机运行
      运行标志M0.0      TON_电机2延时
  ----| |------------(TON)----------
                     PT := T#5S    Q──( ) 电机2Q0.1
```

**答案解读**：顺序启动的核心是"用前一步的状态作为后一步的计时条件"。停止时两台同时断——因为都挂在 M0.0 上。思考：如果要求停止时反过来（2 号先停、1 号延时 3 秒后停），怎么加网络？（参考题07 的延时停止思路。）

### 题13｜闪烁报警电路（振荡器）

- **难度**：中级
- **控制要求**：温度（MW20）超过 80 时：报警灯（Q0.2）以 1Hz 频率闪烁（亮 0.5 秒、灭 0.5 秒），蜂鸣器（Q0.3）长鸣。温度正常后自动恢复。
- **提示**：闪烁源 = 自制振荡器（两个 TON 互相切换）或 CPU 时钟存储器位（CPU 属性启用 MB10 后 M10.5 即 1Hz 脉冲）。两种都练一遍收益最大。
- **参考答案**：

```
网络1：报警条件
      温度MW20                            报警标志M0.2
  ----| |>=80|----------------------------( )----

网络2：振荡器-半周期置位
      闪烁位M0.3(常闭)   TON_闪烁1
  ----|/|--------------(TON)----------
                      PT := T#500MS  Q──(S) 闪烁位M0.3

网络3：振荡器-半周期复位
      闪烁位M0.3         TON_闪烁2
  ----| |--------------(TON)----------
                      PT := T#500MS  Q──(R) 闪烁位M0.3

网络4：报警输出（报警标志与闪烁位串联驱动闪烁）
      报警标志M0.2        闪烁位M0.3        报警灯Q0.2
  --------| |----------------| |----------------( )---

网络5：蜂鸣器长鸣
      报警标志M0.2                          蜂鸣器Q0.3
  ----| |----------------------------------( )----
```

**答案解读**：M0.3=0 时网络2 计时 0.5s 后置位 M0.3；M0.3=1 后网络2 的 IN 断开（其 Q 复位，但 M0.3 已被 S 锁住），网络3 开始计时 0.5s 后复位 M0.3……如此循环，M0.3 就是周期 1 秒、占空比 50% 的方波。网络4 采用 M0.2 与 M0.3 串联结构：报警标志 M0.2 接通时，由闪烁位 M0.3 的 1Hz 方波斩波输出，实现报警灯 1Hz 闪烁。替代方案：CPU 属性 → 系统和时钟存储器 → 勾选启用（字节设为 MB10），M10.5 固定 1Hz，直接代替 M0.3，两个网络全省。

### 题19｜用 FC 封装电机控制（结构化编程入门）

- **提示**：FC 没有背景 DB（无静态存储），自锁必须借助 In/Out 形参——块内读它当反馈、写它当输出。块内一律用 #形参名 编程。
- **参考答案**：

FC_电机控制 块接口：

| 形参名 | 类型 | 说明 |
|---|---|---|
| 启动 | Input: Bool | 启动按钮 |
| 停止 | Input: Bool | 停止按钮 |
| 电机 | InOut: Bool | 输出兼自锁反馈 |

FC 内部（LAD）：

```
网络1：启保停（用形参）
      #启动            #停止             #电机
  ----| |----+-------|/|--------------( )----
             |
      #电机  |
  ----| |----+
```

OB1 中的两次调用：

```
网络1：风机1
      I0.0 ──启动 ─┐
      I0.1 ──停止 ─┤ FC_电机控制
      Q0.0 ──电机 ─┘      (FC_电机控制_风机1)

网络2：风机2
      I1.0 ──启动 ─┐
      I1.1 ──停止 ─┤ FC_电机控制
      Q0.5 ──电机 ─┘      (FC_电机控制_风机2)
```

**答案解读**：核心是 In/Out 参数的"双向"特性：调用时实参 Q0.0 的当前值传进 #电机 作自锁反馈，网络执行后 #电机 的结果又写回 Q0.0。这就是无静态存储的 FC 也能实现自锁的关键。体会结构化编程的收益：逻辑只有一份，改互锁、加保护只改一处，两台风机同时受益；设备越多，省得越多。

### 题20｜流水线材质分拣

**答案解读**：时序链：M0.0 →（星形 Q0.2 + TON 5s）→ M0.1 →（TON 0.5s）→ M0.2 → 三角形 Q0.1。星形断开到三角形吸合之间留 0.5 秒，是星三角改造能否安全运行的关键细节。互锁做了三层：网络3 串切换标志常闭（阶段互锁）、网络3/网络6 互串输出常闭（触点互锁），加上真实电路的接触器硬件互锁，共四重保险——高压电机启动保护，再多的保险都不算多。PLCSIM 验证时可用监控表同时观察 Q0.0/Q0.1/Q0.2 三个输出的切换时序。

### 题22｜十字路口交通灯控制

- **难度**：高级
- **控制要求**：一个 12 秒循环的交通系统：东西方向：绿（Q0.0）4 秒 → 黄（Q0.1）2 秒 → 红（Q0.2）6 秒；南北方向：红（Q0.3）6 秒 → 绿（Q0.4）4 秒 → 黄（Q0.5）2 秒。两方向红绿严格互斥，循环往复。启动按钮 I0.0 开始运行，停止按钮 I0.1 停止（全部灯灭）。
- **提示**：用一个 TON（「TON_主周期」，PT=T#12S）做主时间轴，用它的 ET（已流逝时间）与 T# 常数比较来划分时间段；IN 接"运行标志 AND NOT 自身Q"实现自动循环。比较触点同样支持 Time 类型。
- **参考答案**：

```
网络1：主周期定时器（计满自动归零，循环往复）
      运行标志M0.0      主周期Q(常闭)     TON_主周期
  ----| |--------------|/|------------(TON)----------
                                     PT := T#12S

网络2：东西绿（0~4秒）
      运行标志M0.0     ET<T#4S             东西绿Q0.0
  ----| |------------|  TON_主周期.ET    ( )----
                     |  < T#4S
网络3：东西黄（4~6秒）
      运行标志M0.0     ET>=T#4S   ET<T#6S    东西黄Q0.1
  ----| |------------|  ET >= T#4S ──|/| ET >= T#6S ──( )----
网络4：东西红（6~12秒）
      运行标志M0.0     ET>=T#6S             东西红Q0.2
  ----| |------------|  ET >= T#6S ────────( )----

网络5：南北红（0~6秒）
      运行标志M0.0     ET<T#6S              南北红Q0.3
  ----| |------------|  ET < T#6S ─────────( )----
网络6：南北绿（6~10秒）
      运行标志M0.0     ET>=T#6S   ET<T#10S   南北绿Q0.4
  ----| |------------|  ET >= T#6S ──|/| ET >= T#10S ──( )----
网络7：南北黄（10~12秒）
      运行标志M0.0     ET>=T#10S            南北黄Q0.5
  ----| |------------|  ET >= T#10S ───────( )----
```

（注：网络中 "| ET < T#4S |" 表示一个 Time 类型比较触点，左端取 TON_主周期 的 ET 引脚变量。）

**答案解读**：本题展示"一条时间轴 + 多个比较区间"的设计模式：12 秒一个大周期，ET 就像秒表读数，每个灯绑定自己的时间窗。相比每盏灯独立用定时器接力，此法只有一个"时间源"，灯与灯之间绝不会重叠或空档——因为区间是数学上连续划分的。核对一下：任意时刻东西红（6~12s）恰好覆盖南北绿+南北黄（6~12s），两方向安全互斥。想改配时（比如高峰期绿灯延长），只需改比较常数，结构一行不动。

### 题23｜多级传送带顺序启停

- **难度**：高级
- **控制要求**：三条传送带沿物流方向排列：1 号（Q0.0，最上游）→ 2 号（Q0.1）→ 3 号（Q0.2，最下游）。启动顺序：**逆物流方向**（先开最下游 3 号，隔 2 秒开 2 号，再隔 2 秒开 1 号）——防止货物在未运转的下游堆积；停止顺序：**顺物流方向**（先停最上游 1 号，隔 3 秒停 2 号，再隔 3 秒停 3 号）——让已在带上的货物全部走空。启动按钮 I0.0、停止按钮 I0.1。启动过程中再按停止要能安全处理（本题为简化：启动完成前按停止无效）。
- **提示**：启动链用 TON 接力（「TON_启动2号」2s、「TON_启动3号」2s），停止链同理（各 3s）；用"启动流程标志/停止流程标志"两个 M 位管理阶段，全部完成后切换到"运行中"状态。
- **参考答案**：

```
网络1：启动流程标志
      启动按钮I0.0        停止按钮I0.1        启动流程M0.0
  ----| |----------+-------|/|-------------(S)----
                   |

网络2：3号带立即启动（最下游先开）
      启动流程M0.0                           传送带3Q0.2
  ----| |------------------------------------( )----

网络3：2秒后2号带
      启动流程M0.0      TON_启动2号
  ----| |------------(TON)----------
                     PT := T#2S    Q──( ) 传送带2Q0.1

网络4：再2秒后1号带，启动流程结束
      TON_启动2号(Q)    TON_启动3号
  ----| |------------(TON)----------
                     PT := T#2S    Q──┬( ) 传送带1Q0.0
                                       └(S) 运行中M0.2
                                        (R) 启动流程M0.0

网络5：停止流程标志
      停止按钮I0.1      运行中M0.2           停止流程M0.3
  ----| |--------------| |------------------(S)----
                                        (R) 运行中M0.2

网络6：停1号（最上游先停）
      停止流程M0.3                           传送带1Q0.0
  ----|/|------------------------------------( )----
      (停止流程一出现，Q0.0 立即断)

网络7：3秒后停2号
      停止流程M0.3      TON_停止2号
  ----| |------------(TON)----------
                     PT := T#3S    Q──( ) (R) 传送带2Q0.1

网络8：再3秒后停3号，流程结束
      TON_停止2号(Q)    TON_停止3号
  ----| |------------(TON)----------
                     PT := T#3S    Q──┬(R) 传送带3Q0.2
                                       └(R) 停止流程M0.3
```

（说明：网络7、8 中对输出的复位建议改写成"输出 = 条件"的形式更清晰，例如 2 号带输出 = (运行中 M0.2 OR 启动流程 M0.0 的对应阶段) AND NOT TON_停止2号.Q，此处给出的是便于理解的接力示意。）

**答案解读**：两条时间链方向相反——启动"下游→上游"、停止"上游→下游"，这是多级输送系统的标准范式，逻辑本质与题21 星三角、题12 顺序启动同源：**用前一步的完成信号作为后一步的开始条件**。经验法则：启动间隔取"最慢货物走完一段带的时间"，停止间隔取"货物走完全部剩余路程的时间"。此题继续扩展的抓手：把间隔时间做成 DB 设定值（可从 HMI 修改）、启动中途按停止的 abort 处理、任一带过载（模拟输入）时全线急停。

### 题24｜通用电机控制 FB 与多次调用

- **难度**：高级
- **控制要求**：设计一个可复用块 FB_电机控制：输入 启动、停止、故障（Bool）；输出 运行（Bool）、累计运行秒数（Int）；功能：标准启保停 + 故障禁止运行 + 运行期间按秒累计运行时间（用 1Hz 时钟位 M10.5 的上升沿计数）。在 OB1 中调用三次，控制三台风机：风机1 = I0.0/I0.1/Q0.0，风机2 = I1.0/I1.1/Q0.5，风机3 = I1.2/I1.3/Q0.6，故障输入仿真时用 I1.4/I1.5/I1.6 代替。
- **提示**：FB 有背景 DB（有记忆），自锁标志放 Static；时间累计 = 运行 AND M10.5 上升沿 时累计值 +1；三次调用各挂一个单背景 DB（「电机1_实例」等），或使用多重实例。
- **参考答案**：

FB_电机控制 接口：

| 形参名 | 区段 | 类型 | 说明 |
|---|---|---|---|
| 启动 | Input | Bool | 启动按钮 |
| 停止 | Input | Bool | 停止按钮 |
| 故障 | Input | Bool | 故障信号（=1 禁止运行） |
| 运行 | Output | Bool | 输出到接触器 |
| 累计运行秒 | Output | Int | 运行时间累计 |
| 运行标志 | Static | Bool | 自锁状态（记忆在背景DB） |
| 秒脉冲边沿位 | Static | Bool | 1Hz 时钟脉冲边沿检测存储位 |

FB 内部（LAD）：

```
网络1：启保停 + 故障禁止
      #启动         #故障(常闭)   #停止(常闭)        #运行
  ----| |----+------|/|-----------|/|--------------( )----
             |
      #运行  |
  ----| |----+

网络2：运行秒数累计（在运行状态下，遇 1Hz 时钟 M10.5 上升沿累加 1 秒）
      #运行         时钟1HzM10.5            #累计运行秒
  ----| |----------------|P|----------------(ADD: +1)----
                   (边沿位: #秒脉冲边沿位)     (结果存回#累计运行秒)
```

OB1 中三次调用：

```
网络1：风机1
      I0.0 ──启动 ──┐
      I0.1 ──停止 ──┤  FB_电机控制        (背景DB: 电机1_实例)
      I1.4 ──故障 ──┤
      Q0.0 ──运行 ←─┤
      MW40区 ──累计运行秒 ←─┘   (可映射到"DB_电机数据".风机1秒数)

网络2、3：风机2、风机3 同理，换成 I1.0/I1.1/Q0.5 与 I1.2/I1.3/Q0.6
```

**答案解读**：这是从"写程序"迈向"做产品"的一步。FB 与 FC 的本质区别在 Static 区：运行标志、边沿辅助位都存在各自的背景 DB 里，因此同一个 FB 的三个实例互不干扰、各自带记忆。收益清单：三台风机的控制逻辑只维护一份；新增第四台风机 = 加一次调用；要加"过载自动停机+报警"功能，改 FB 一处，全部风机同时升级。进阶方向：把三次调用合并到一个父 FB 中做成多重实例（OB1 只调用父 FB 一次），块结构更整洁。

### 题25｜自动灌装生产线综合控制

- **难度**：高级
- **控制要求**：灌装机节拍如下：①按启动按钮 I0.0，传送带 Q0.0 运行；②空瓶到达灌装位（传感器 I0.3 上升沿）→ 传送带停止，灌装阀 Q0.5 打开，灌装 3 秒；③灌装完成阀关闭，成品计数 +1（存 MW30），传送带自动恢复运行，等待下一瓶；④每灌装 24 瓶（一箱）报警灯 Q0.2 亮 2 秒提示换箱（TP），计数继续；⑤灌装过程中液位模拟量（IW64，0~27648 对应 0~100%）换算为百分比存 MD40，供 HMI 棒图显示，液位 >= 90.0 时蜂鸣器 Q0.3 提示；⑥停止按钮 I0.1：灌装阀立即关闭、传送带停止；清零按钮 I0.4 清成品计数。HMI 显示：计数 MW30、液位 MD40。
- **提示**：状态法拆解：空闲 → 灌装中（M0.0，IN=瓶到位脉冲，停止条件=TON 3s 计满）→ 计数脉冲 → 回空闲。传送带输出 = 运行标志 AND NOT 灌装中。计数用 CTU（「CTU_成品计数」，PV 不设限），满 24 用比较触发 TP（「TP_换箱提示」）。液位用 NORM_X/SCALE_X。
- **参考答案**：

```
网络1：系统运行标志
      启动按钮I0.0        停止按钮I0.1        运行标志M0.5
  ----| |----------+-------|/|-------------( )----
                   |
      运行标志M0.5 |
  ----| |----------+

网络2：瓶到位进入灌装状态
      运行标志M0.5      瓶检测I0.3          灌装中M0.0
  ----| |--------------|P|------------------(S)----
    (边沿存储位M1.0)

网络3：灌装计时3秒
      灌装中M0.0        TON_灌装计时
  ----| |------------(TON)----------
                     PT := T#3S    Q──┬(R) 灌装中M0.0
                                       └( ) 计数脉冲M0.1

网络4：成品计数
      计数脉冲M0.1      CTU_成品计数
  ----|P|------------(CTU)------
      清零按钮I0.4 ──R   PV := 9999
      (边沿存储位M1.1)   CV ──( ) 送到MW30

网络5：满一箱提示
      计数值MW30        TP_换箱提示
  ----| |>=24|-------(TP)----------
                     PT := T#2S    Q──( ) 报警灯Q0.2

网络6：传送带输出（灌装时必须停）
      运行标志M0.5      灌装中M0.0(常闭)    传送带Q0.0
  ----| |--------------|/|------------------( )----

网络7：灌装阀输出
      灌装中M0.0                             灌装阀Q0.5
  ----| |------------------------------------( )----

网络8：液位百分比换算
      IW64 ──(NORM_X: 0~27648 → 0.0~1.0)──(SCALE_X: 0.0~100.0)──( ) 液位MD40

网络9：高液位提示
      液位MD40                               蜂鸣器Q0.3
  ----| |>=90.0|-----------------------------( )----
```

**答案解读**：本题是全课程的"小综合"：边沿（瓶到位单次触发）、TON（灌装定时）、TP（换箱提示脉冲）、CTU（成品计数）、比较（满箱/高液位）、NORM_X/SCALE_X（模拟量）、HMI 数据（MW30/MD40）、互锁（灌装时停带）全部上阵。三个易错点提前预警：①网络2 必须用 P 边沿，否则瓶子在位期间 M0.0 反复置位；②网络3 用 TON 的 Q 同时复位 M0.0 和产生计数脉冲，脉冲宽度恰好一个扫描周期，网络4 必须再用一次 P 或确保 CTU 只在脉冲周期计一次；③液位百分比把 100 写成 100.0（Real），写成整数 100 会编译报类型错误。PLCSIM 验证顺序建议：先单测灌装时序（监控表手动拍 I0.3），再连测计数/换箱，最后接 HMI 看棒图与数字联动。
